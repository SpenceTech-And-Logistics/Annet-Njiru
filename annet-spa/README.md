# Annet Wanjiku Njiru: single-page site (React + Vite)

- All text lives in `src/content.js`. Contact details (email, phone, socials, optional Formspree id) are blank; fill them in and empty ones stay hidden.
- Photo: `public/images/portrait.jpg`. To add more photos, drop them in `public/images/` and list them in `gallery` in `content.js` (a Gallery section appears automatically).
- Run: `npm install`, `npm run dev`. Deploy: `npm run build`, upload `dist/`.
- Facts used come only from the supplied pages: 20+ years; CEO of Big Win Agencies; marketing, entrepreneurship, mediation (ADR), alternative health and business consultancy; eight named clients.
- The "5 disciplines" and "8 organisations" figures are counts of what the pages list.
